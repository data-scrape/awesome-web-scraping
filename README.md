# Awesome Web Scraping

Awesome Web Scraping - Curated list of scraping tools, APIs, and frameworks

## What belongs in this list

A curated map of libraries, APIs, MCP servers, and operating practices relevant to **local-market research and lead-list enrichment**. Entries should help a reader make a concrete implementation choice—not inflate a directory.

### Evaluation criteria

| Criterion | What to look for |
|---|---|
| Data fit | Does it produce the fields and sources your workflow needs? |
| Maintenance | Is the project active, documented, and transparent about limitations? |
| Integration | Does it support the runtime, API model, or MCP client you use? |
| Governance | Can you operate it responsibly with source, retention, and review controls? |
